# Генератор тестовых вопросов из PDF-лекций

Проект по практике: приложение для преподавателей ИМЭС — загружаешь PDF
лекции, получаешь тестовые вопросы (множественный выбор, верно/неверно,
на соответствие), сгенерированные ИИ, с просмотром в браузере.

## Стек

- **Python** — pdfplumber (парсинг PDF), GigaChat API (генерация вопросов)
- **Streamlit** — интерфейс для преподавателя, в фирменном стиле ИМЭС
- **openpyxl / lxml** — экспорт в Excel / QTI (следующий этап)

Весь стек бесплатный и доступен из России без VPN.

## Установка

```bash
# 1. Клонировать репозиторий и перейти в папку проекта
git clone <url> && cd quiz-generator

# 2. Создать окружение и поставить зависимости
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Настроить ключ GigaChat
cp .env.example .env
# открыть .env и вписать реальный GIGACHAT_CREDENTIALS
# (получить в личном кабинете developers.sber.ru — тариф Freemium, бесплатно)

# 4. Запустить интерфейс
streamlit run app.py
```

Настройки самого Streamlit (тема оформления, отключённая телеметрия,
запрет доступа с других устройств в сети) уже лежат в `.streamlit/config.toml`
и подхватятся автоматически.

## Известное ограничение: точность правильного ответа

GigaChat иногда указывает неверный индекс правильного варианта в вопросах
с множественным выбором, даже когда собственное объяснение модели верно
(наблюдалось повторно на практике). Индекс "в никуда" (за пределами списка
вариантов) отлавливается автоматически на уровне валидации — такой вопрос
просто не дойдёт до преподавателя. А вот смысловые ошибки (верный индекс
технически, но не тот факт) код поймать не может.

**Поэтому у каждого вопроса с множественным выбором есть поле `explanation`**
(видно и в интерфейсе, и в JSON) — краткое объяснение модели, на чём основан
её выбор. Перед использованием сгенерированных вопросов со студентами
рекомендуется быстро просмотреть их — это заложено и в текст самого
интерфейса ("перепроверяйте вопросы — ИИ может допускать ошибки").

## Важное про парсинг PDF

Модуль `pdf_parser.py` покрывает **цифровые PDF** (презентации/лекции
с текстовым слоем — типичный экспорт из PowerPoint/Word/LaTeX).

Если на реальных материалах ИМЭС встретятся страницы без текстового слоя
(сканы), парсер их не сломает, но пометит флагом `likely_scanned=True`
(проверяется по количеству извлечённого текста на странице) — это
задокументированный триггер для подключения OCR (pytesseract) отдельным
модулем позже, если понадобится.

## Приватность данных

- Реальные лекционные материалы ИМЭС **не хранятся в репозитории**
  (`data/uploads/`, `data/output/` в `.gitignore`) — только обезличенные
  тестовые файлы в `data/sample/`.
- Ключ GigaChat хранится в `.env`, который тоже в `.gitignore` и никогда
  не попадает в git (проверено: `git log --all --full-history -- .env`
  пуст на всём протяжении истории репозитория).
- Streamlit запускается только на `localhost`, анонимная телеметрия
  отключена (`.streamlit/config.toml`).
